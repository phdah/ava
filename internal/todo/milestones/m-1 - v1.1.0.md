## Description

Ava 1.1.0 feature milestone.

While this milestone is active, all newly created internal roadmap tasks must target `m-1`. Do not create or assign new work to another release milestone implicitly.

If proposed work cannot fit within Ava 1.x compatibility and would require a `2.0.0` major release, defer creating that roadmap task and inform the requester that the scope must be re-evaluated. The requester must explicitly decide whether to narrow or change the work so it fits `v1.1.0`, or to establish a separate major-version milestone and update the roadmap admission policy.
