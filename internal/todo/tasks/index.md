# Internal roadmap tasks

This directory contains unfinished native Backlog.md tasks in the Ava internal roadmap.

Use Backlog.md as the task index. Query `To Do` tasks and dependencies through the CLI to select executable work. `Parked` and `In Progress` tasks remain here as active lifecycle states. Tasks with status `Done` are moved by Backlog.md cleanup into `../completed/`, which is the canonical finished-task location.

A `Done` task labeled `Won't Fix` still records an intentional non-implementation closure and belongs in `../completed/` after cleanup.
