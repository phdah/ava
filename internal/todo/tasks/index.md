# Internal roadmap tasks

This directory contains every native Backlog.md task in the Ava internal roadmap, regardless of lifecycle state.

Use Backlog.md as the task index. Query `To Do` tasks and dependencies through the CLI to select executable work. `Done` and `Parked` remain in this directory as normal task states and are not moved to a separate completed directory. A `Done` task labeled `Won't Fix` records an intentional non-implementation closure while still counting as complete in Backlog.md.
