# Backlog.md Integration

This phase evaluates the exact adoption model and implements Backlog.md as Ava's selected Markdown-native agile board for internal todos and project task management.

This is not a generic task-board compatibility phase. Backlog.md is the selected tool. Its native Markdown files remain reviewable Git content, and no GitHub Pages site, hosted service, or external database is required.
