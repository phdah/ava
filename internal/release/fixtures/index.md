# Validation Fixtures

Machine-readable fixtures that freeze public contract examples and maintained release validation scenarios.

- [Conformance matrix](conformance-matrix.json) - Structural, metadata, discovery, installation, filesystem safety, transaction, migration, maintenance, uninstall, semantic, role-routing, host, trust, upgrade-graph, and publication cases.
- [Release-please policy](release-please-policy.json) - Bootstrap identity, Conventional Commit title classification, changelog visibility, and alpha, RC, and stable channel settings.
- [Release upgrade policy](release-upgrade-policy.json) - Initial release identity and protected direct source versions used by release PR validation.
- [Semantic-impact assessment](semantic-impact-assessment.json) - Reviewed `false` and `true` release-edge examples that distinguish managed changes from possible project-owned semantic dependencies while preserving the maintainer-judgment boundary.
- [Adjacent upgrade catalog](adjacent-upgrade-catalog.json) - Two-edge self-contained catalog with one semantic edge, one no-op semantic edge, retained supported sources, immutable edge digests, and semantically lagging path resolution.
- [Document update metadata](document-update-metadata.json) - Creation, meaningful mutation, trivial mutation, repeated mutation, legacy metadata, malformed metadata, temporal consistency, verification staleness, and reserved-document cases.
- [Knowledge hierarchy promotion](knowledge-hierarchy-promotion.json) - Durable-subject classification, semantic subgroup promotion, temporary headings, cross-links, and Project Steward handoff cases.
- [Calendar verification](calendar-verification.json) - Relative-date reference contexts, weekday consistency, week/month/year boundaries, leap day, historical source anchoring, unresolved periods, and semantic-review contradictions.
- [Inbox ingestion fidelity](inbox-ingestion-fidelity.json) - Multi-topic source inventories, uncertainty preservation, claim attribution, renderable footnotes, empty sources, and final-state count reconciliation.
- [Inbox scoped history](inbox-scoped-history.json) - Pre-existing log preservation, no-op routine ingestion, single-entry qualifying ingestion, and Project Steward or fixture-preparation cleanup handoff cases.
- [Root routing](root-routing.json) - Unconditional managed-state gating, roleless clarification, same-role continuity, fresh rerouting triggers, warranty-prompt bypass prevention, and explicit unresolved-routing behavior.
- [Review sufficiency](review-sufficiency.json) - Acceptance and audit standards, finding admission, satisfied re-review termination, remediation regressions, and explicit exhaustive audit.
- [Ava Maintenance](ava-maintenance.json) - Installation reporting, managed integrity, installer-backed deterministic recovery, terminal finalization, semantic handoff, host capability and access, and safe role-led removal cases.
- [Synthetic qualification vault](synthetic-qualification-vault/) - Reviewed canonical facts, deterministic raw corpus generator, external image specifications, oracle and run-manifest contracts, validators, and qualification variant families.
