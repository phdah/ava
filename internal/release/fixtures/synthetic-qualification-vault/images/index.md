- [Aurora status board](2025-06-20-aurora-status-board.png) - Fictional work-status image for the June corpus.

Generated vaults, copied corpus images, run evidence, and transcripts remain repository-external. Do not edit or recompress these pinned bytes in place. A replacement requires a reviewed manifest update and complete fixture requalification.
