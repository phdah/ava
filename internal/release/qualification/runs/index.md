# Qualification Run Evidence

This directory contains only compact evidence generated by `internal/release/qualify-release.sh`.

Each run may add a run record, issue inventory, session inventory, and independent audit report. Raw release assets, generated corpus copies, isolated workspaces, command output, and full transcripts remain outside the repository and are referenced by digest.

Generated evidence is intentionally left uncommitted for maintainer and user review. A `failed` or `needs-review` run must never be relabeled as `awaiting-user-signoff` by editing summary state alone. Explicit user acceptance is a later user-owned action and is not performed by the qualification command.
