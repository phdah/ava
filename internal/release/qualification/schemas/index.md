# Qualification schemas

These schemas define the current qualification state and evidence contracts.

- [Configuration schema](config.schema.json)
- [Release-pair catalog schema](pair-catalog.schema.json)
- [Current-state schema](current-state.schema.json)
- [Deterministic final run-record schema](qualification-run-record.schema.json)

Historical run records under `../runs/` are preserved as immutable evidence even when an older record predates the current schema.
