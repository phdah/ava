# Ava Distribution Contracts

This directory is the authoritative public home for repository-level distribution contracts and machine-readable schemas.

These files define release, installation, upgrade, and compatibility behavior. They are not automatically installed into projects. Release assembly includes only content explicitly declared by the release manifest.
