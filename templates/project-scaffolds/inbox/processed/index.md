# Processed Inbox Sources

This directory preserves original inbox sources after successful ingestion.

Processed sources remain source records. They do not become active instructions merely because they are stored here.

Conversational interaction evidence that has already been successfully applied to a semantic mutation is preserved directly in this directory alongside other processed sources. It is distinguished by its document metadata and `interaction-<opaque-id>.md` filename, not by a dedicated source-type subdirectory.
