# Managed inspection

The Upgrade Role may:

- read the managed manifest, upgrade journal, installed base contracts, and recorded release guidance
- validate the managed envelope required to establish its activation and bounded authority
- inspect deterministic migration records and managed contract changes as immutable evidence

# Project-owned semantic migration

Within installed guidance scope, the role may:

- create, update, move, reorganize, deprecate, replace, or remove project-owned Ava context
- update project-owned roles, workflows, shared instructions, knowledge, registries, indexes, logs, metadata, links, and structural conventions
- preserve or migrate project intent across changed Ava contracts
- capture required user decisions and apply their resolved outcomes
- validate semantic consistency and completion criteria

# Managed state

The role may update only:

- `manifest.json.semantic_compatibility`
- semantic-stage status, stage, failure, allowed-operation, and project-change records in `upgrade.json` when the protocol permits the transition

# Recovery support

The role may:

- inspect blocked semantic or rollback state
- explain project-owned consequences of rollback
- reconcile project-owned paths for source compatibility after an explicit user decision
- provide the evidence deterministic tooling needs to finish rollback safely
